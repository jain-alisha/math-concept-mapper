# November 16 UI audit follow-up

Scope: the reported bugs and usability problems in Parts 1–2 of `Span_UI_Audit.pdf`. Part 3 proposes new features; typed arrows, auto-layout, expert comparisons, collaboration and new export formats are not included in this release.

| Bug | Resolution |
|---|---|
| 1 Sample overwrites draft | Already fixed in PR13: isolated sample draft key and reload behavior. |
| 2 My Maps intermittent 401 | Refresh near-expiry sessions, retry the owner-scoped read once on token rejection, and offer Try again with a reason on failure. |
| 3 Student teacher switch | Remove browser role switching; disable and revoke the legacy RPC. Production SQL verifies both authenticated and guest execute privileges are false. Existing teacher accounts retain their roles. |
| 4 Fit map | Scale to map bounds, reserve visible hint space and add origin padding. Initial load fits the map too. |
| 5 New concepts off-screen | Use zoom-aware viewport placement, collision search, and reveal the new node. |
| 6 Stale toolbars | Clear selection controls on panels/dialogs; clamp overlays inside the canvas; put dialogs above controls. |
| 7 Fragile ghosts | Keep suggestions through background clicks, Fit and zoom; fit their bounds; widen pills; clamp controls and position Why beside the ghost. Explicit close/Escape still dismisses them. |
| 8 Reciprocal arrows | Confirm a reverse/path-forming link, preserve deliberate mutual relationships, then invite an explanation for new ordinary arrows. |
| 9 Dashboard styling | Style section navigation, searches, selects and card actions; keep disclosures/actions within card frames. |
| 10 Insight layout | Inline 18px disclosure controls, nonwrapping badges and independent card columns. Print retains ordinary flow. |
| 11 Inconsistent header | Shared link order, Privacy link, active dashboard state, brand and account controls. |
| 12 Accessibility | Concept-first accessible names, labeled Browse checkbox, main landmarks/skip links, hidden decorative home illustrations and reduced-motion CSS. |

Additional polish: multiline arrow explanations name both endpoints; gold/gray legend; map-check result offers a concrete next step and Close; remove duplicate Clear action and explain checkpoints; full-width timeline assignment; existing timeline deletion confirmation retained; sidebar toggle gets its own row; searchable student maps gain type/sort controls and readable counts; timeline labels wrap and include snapshot counts; taught concepts fold by unit with select/clear controls and search; merge Probability model/models while retaining legacy alignment; rename Student progress to Map size; vary fictional suggestion provenance; preview theme node palettes; simplify hero actions, center beta cards/subtitle, unclip Explore illustration, and keep short-page footers at the bottom. Account deletion moves to Account; students can leave their own classes without deleting maps.

Per owner request, direct contact and support links are removed. Username-only password recovery is explicitly unavailable; no private email is published.

Distinct statistical concepts (Center, Spread, Center and spread) are retained. Repeated concepts across curriculum units retain unit context and one canonical identity. New themes and teacher charts remain optional enhancements rather than fabricated fixes to existing behavior.

Validation: automated JavaScript/database tests, Python recommendation tests, whitespace checks, plus rendered preview and production checks. Live checks cover fitting, persistent suggestions, overlays, dashboard layout and Settings. Real expired-token timing, physical screen readers/touch hardware and native export dialogs are not certified by these checks.
