## Remaining limits

Audit 23 remains an owner decision: username accounts need a verified private
support channel. The current support page already warns against posting private
student information to public GitHub issues. This branch does not invent a
recovery address or introduce an unverified password-reset mechanism.

Physical touch-device behavior, real signup and email delivery, completed native
PDF downloads, destructive production deletion, and elapsed-time retention are
not certified by this audit. Database regression tests cover permission,
checkpoint, account deletion and retention logic without deleting live records.

Both browser environments refused the workspace localhost preview. Automated DOM
and coordinate regressions therefore accompany these changes; final pixel/layout
verification must use an accessible branch preview before production rollout.

This branch changes existing activity update calls under existing teacher RLS;
it requires no database migration. Deploy the matching Python service for the
backend cross-grade graph behavior. The requested pilot role toggle remains.
