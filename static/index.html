Map how math concepts connect

What you can do

🗂️

Drag-and-drop curriculum

Browse a full grade-by-grade, unit-by-unit math concept hierarchy in the sidebar and drop any topic onto the canvas.

🔗

Link & annotate

Draw arrows between concepts to show relationships, and attach notes to any connection to explain the "why."

🤖

AI recommendations

Long-press any node to get smart suggestions — prerequisites, successors, and semantically related topics — powered by a Flask backend.

✏️

Custom concepts

Not in the curriculum? Add your own labeled concept nodes directly from the sidebar.

How it works

1

Start mapping

Drag any topic from the concept sidebar onto the canvas, or type in a custom concept of your own.

2

Connect the dots

Double-click and drag from one node to another to draw a relationship. Double-click a link to add a note explaining it.

3

Get AI suggestions

Long-press (hold the mouse) on a node to open the AI panel — it analyzes your current map and the curriculum structure to recommend what to add next.

Under the hood

The interactive canvas is plain HTML/SVG and JavaScript. Recommendations are computed by a Python/Flask backend (ai_recommender.py) that combines curriculum structure, graph analysis with networkx, and semantic similarity from sentence-transformers. To see AI suggestions in the playground, run the backend locally first with python ai_recommender.py — see the README for setup steps.
