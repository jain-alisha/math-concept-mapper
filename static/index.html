Start with a topic. See where it leads.

Span turns a flat list of curriculum topics into a map that shows how ideas connect. Teachers can use it to plan a sequence, students can trace how one topic builds into another, and curriculum designers can spot gaps or missing links.

Three ways it helps

Map an entire curriculum

Browse concepts by grade and unit, then drag any topic directly onto the canvas.

Show how concepts connect

Draw arrows between concepts to mark prerequisites, extensions, and related ideas.

Find related concepts

Long-press any node to get suggested prerequisites, next steps, and related topics.

For Teachers

See where students may be missing prerequisite connections.

Build the path you expect students to follow through a unit, then compare it with the connections they actually make.
